# Голосование через Google Таблицу

Таблица: https://docs.google.com/spreadsheets/d/1dy35NRxTSYDKEDIgACOt3cJnRHPx7jtMTkaLzHTIzTs/edit
Опубликованный скрипт: https://script.google.com/macros/s/AKfycbx3fnef6NNMLLSMIfYSqXP0uCPhD_T49zEFATv6VUzpYh9tq8DSUmz5G_5L_PN3ehFJvg/exec

Сайт обращается напрямую к опубликованному Google Apps Script. Сервер на
`cowork.ru` для голосования не нужен. Голоса с телефонов и экрана сцены
считываются из одной таблицы. Лист `Голоса` содержит время, случайный ID
браузера, номер вопроса и ответ.

## Настройка владельцем таблицы

1. Откройте таблицу под аккаунтом с правом редактирования. В меню выберите
   **Расширения → Apps Script**.
2. Замените содержимое `Code.gs` кодом из [`scripts/voting-sheet/Code.gs`](scripts/voting-sheet/Code.gs).
3. Сохраните проект. В редакторе выберите функцию `setupVotingSheet`, нажмите
   **Выполнить** и подтвердите доступ к таблице. Появится лист `Голоса`.
4. Нажмите **Развернуть → Новое развертывание → Веб-приложение**. Выберите
   **Выполнять от имени: Я** и **Доступ: Все**. Скопируйте URL, оканчивающийся
   на `/exec`. Таблицу при этом не требуется открывать для всех.
5. Адрес опубликованного веб-приложения уже указан в `src/lib/voting.ts`.
   При развёртывании этого кода на `cowork.ru` отдельная переменная окружения
   для голосования не требуется. Если URL развертывания изменится, обновите
   адрес в коде или задайте `NEXT_PUBLIC_VOTING_APPS_SCRIPT_URL` при сборке.
6. Откройте страницу участника `/vote/question-1/`, проголосуйте и проверьте
   новую строку на листе `Голоса`. Откройте `/vote/question-1/results/` на
   другом устройстве: результат обновляется каждые 5 секунд. Общий отчёт:
   `/vote/results/`.

`NEXT_PUBLIC_VOTING_APPS_SCRIPT_URL` имеет приоритет над адресом по умолчанию.
Чтобы временно включить прежний демонстрационный режим в `localStorage`,
задайте эту переменную пустой строкой и не задавайте
`NEXT_PUBLIC_VOTING_API_BASE_URL`. Голоса в этом режиме не синхронизируются.

Во время подключения был добавлен один тестовый голос «Да» по вопросу 1.
Перед мероприятием удалите соответствующую строку на листе `Голоса`, если
итоги должны начинаться с нуля.

Ограничение: один голос по вопросу на браузер. При очистке данных браузера
посетитель сможет голосовать снова. Публичный Apps Script URL не является
секретом, поэтому решение подходит для конференционного опроса без строгой
идентификации и защиты от намеренной накрутки.
