Агенты

Агенты — это ИИ-сотрудники, нацеленные на выполнение конкретных задач. В отличие от универсального чат-бота, каждого агента можно настроить под определенную роль: указать набор навыков, инструменты и коннекторы, а также четко прописать последовательность действий и желаемый результат.

Агентов можно использовать в личных задачах, в задачах пространства и добавлять их как общих агентов пространства.

Добавление агента в задачу

Для добавления агента нажмите Добавить агента и выберите нужного из списка.

Возможности агентов

В агентах вы можете:

  • Вызывать инструменты и навыки — просто укажите название.

  • Использовать коннекторы — укажите название коннектора в сценарии получения или отправки данных.

  • Выполнять Python-скрипты — добавьте текст скрипта в инструкцию агента. Поддерживаются не все возможности языка Python.

Действия с агентами

Создание агента

В разделе Агенты созданные вами агенты видны только вам.

Для создания агента:

  1. В разделе Агенты нажмите Создать агента.

  2. Укажите:

    • Название.

    • Описание — видно в карточке агента.

    • Инструкция — укажите порядок действий агента естественным языком.

    • Навыки — с помощью кнопки добавьте навыки, доступные агенту. По умолчанию добавлены все системные навыки.

Просмотр доступных агентов

Доступные вам агенты находятся в разделе Агенты, в основном меню.
В разделе можно найти агента по названию и отфильтровать по признаку Все и Личные (созданные вами).

Помимо личных агентов, в разделе находятся общие.

Тестирование агента

Агента можно протестировать, не создавая отдельную задачу.

Для тестирования агента, в разделе Агенты на карточке агента нажмите Запустить — откроется окно агента с его настройками и полем ввода запроса.
Если агент создан вами, его тут же можете отредактировать, нажав Редактировать, а затем снова продолжить тестирование.

Редактирование агента

Вы можете редактировать только созданных вами агентов.

Для редактирования агента, в разделе Агенты, в карточке агента, выберите → Редактировать. Или откройте карточку агента и нажмите Редактировать.

Удаление агента

Вы можете удалять только созданных вами агентов.

Для удаления агента, в разделе Агенты, в карточке агента, выберите → Удалить — агент станет недоступным для текущих и новых задач. При этом агент также удалится из всех пространств.
