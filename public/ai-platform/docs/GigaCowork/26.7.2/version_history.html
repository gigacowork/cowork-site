История изменений

Версия 26.7.2

Добавлено:

  • В GigaCowork появилась ролевая модель, позволяющая настраивать доступ к административным разделам системы. Управлять ролями можно в новом разделе Роли.Подробнее.

  • Для администраторов добавился раздел «Аудит событий» с событиями действий пользователей. Подробнее.

  • Новое в коннекторах:

    • Добавилась интеграция с 1С. Предустановленный коннектор подключается к одной базе, а для работы с несколькими базами можно настроить собственные MCP-коннекторы. Подробнее.

    • По запросу к администратору стенда теперь можно подключить коннекторы партнеров: Pooling.me, YClients MCP, MCP-PROSTOR, Profitbase.

    • В разделах «Коннекторы» (пользовательском и административном) появились подсказки по подключению коннекторов.

  • Структуру документов теперь можно менять прямо в пространстве. Для этого:

    • Появилась возможность создавать пустые папки.

    • Документы и папки теперь можно выбирать и перетаскивать с помощью мышки между папками пространства.

    • Над таблицей документов добавилась панель действий. Она появляется, если выбрать документ или папку, а ее кнопки применяются ко всем выбранным объектам.
      Подробнее.

Версия 26.7.1

Добавлено:

  • Появилась возможность создавать регулярные задачи, которые выполняются автоматически по настроенному расписанию. Подробнее.

  • Добавился раздел Главная, в нем находится дашборд по текущим задачам и пространствам пользователя.

  • В панели просмотра появилась возможность редактировать отдельные блоки документов и диаграмм. Подробнее.

Версия 26.6.4

Добавлено:

  • Появилась возможность добавлять собственные MCP-коннекторы. Подробнее.

  • Добавились новые возможности совместной работы в пространствах: все участники пространств теперь могут загружать в них документы и добавлять навыки. Также в пространствах теперь можно создавать общие команды и копировать их между пространствами. Подробнее.

  • Для администраторов добавилась возможность массово приглашать пользователей, загрузив CSV-файл с адресами почт сотрудников. Подробнее.

  • GigaCowork научился строить mermaid-диаграммы.

  • Расширились возможности редактирования и форматирования word-файлов.

Версия 26.6.3-2

Теперь задачу можно ставить голосом: отправьте голосовое сообщение, GigaCowork сам преобразует его в текст перед отправкой. Подробнее.

Версия 26.6.3-1

В GigaCowork появились агенты. Агенты — это ИИ-сотрудники, нацеленные на выполнение конкретных задач. В отличие от универсального чат-бота, каждого агента можно настроить под определенную роль: указать набор навыков, инструменты и коннекторы, а также четко прописать последовательность действий и желаемый результат. Агентов можно создавать как для личных задач, так и добавлять в пространство для совместной работы. Подробнее.

Версия 26.6.3

Добавлено:

  • Добавилась поддержка коннекторов RetailCRM и Huntflow. Подробнее.

  • Пространства теперь можно архивировать. Подробнее.

  • В личное меню пользователя добавлена корзина: туда перемещаются все удаленные пространства. При необходимости их можно восстановить. Подробнее.

  • Администраторы теперь могут отзывать приглашения пользователям, но только пока они не авторизовались в системе. Подробнее.

Версия 26.6.2

Добавлено:

  • GigaCowork научился строить графики — просто попросите об этом в задаче. Можно строить графики на основе загруженных файлов или на основе информации в сети.

  • Теперь навыки и команды можно создавать из чата. Достаточно написать Создай навык…​ и описать, какой навык должен быть создан. Аналогично работает создание команды.

  • Появилась возможность изменять отображаемое в системе имя и фамилию пользователя. Подробнее.

  • В таблице раздела Пользователи теперь отображаются пользователи, которым выслано приглашение, но которые еще не зарегистрировались в системе. Статус таких пользователей — Приглашен.

  • В окне коннектора появились фильтры по инструментам. Там же добавилась кнопка массовой смены состояния инструментов.

Изменено:

  • Вход в систему стал еще безопаснее: теперь для него требуется двухфакторная аутентификация (2FA). Подробнее.
    Для администраторов добавилась возможность сброса двухфакторной аутентификации пользователей в разделе Пользователи. Подробнее.

  • Улучшен просмотр вложений. Теперь изображения, файлы и графики открываются не в отдельном окне, а на панели просмотра. При этом не блокируется чат задачи, что делает работу быстрее и удобнее.
