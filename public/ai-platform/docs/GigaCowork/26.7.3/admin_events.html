Аудит событий

В разделе Администрирование → Аудит событий хранятся события действий пользователей. Также в разделе можно удалять файлы, связанные с этими событиями.

Просмотр событий

События в разделе Администрирование → Аудит событий можно фильтровать по типу, дате возникновения и искать в строке поиска.

Строка поиска событий ищет по параметрам:

  • Описание события.

  • Тип события.

  • Инициатор события: почта, отображаемое имя, ID.

  • ID сессии.

  • ID пространства. Обратите внимание, ID пространства не отображается в параметрах события, однако по нему можно искать.

  • Ресурсы события. Например, ID пространства, участник пространства, команда, навык и т.д.

Столбцы в таблице событий можно настроить. Для этого нажмите Настроить столбцы.

Доступные типы событий

Администрирование:

  • Отозвано приглашение пользователя.

  • Созданы приглашения пользователей.

  • Запрошен сброс пароля.

  • Сброшена двухфакторная аутентификация.

  • Выполнен выход из системы.

Агенты:

  • Создан агент.

  • Удален агент.

  • Обновлен агент.

  • Удалена версия агента.

  • Добавлен агент рабочего пространства.

  • Удален агент рабочего пространства.

  • Обновлен агент рабочего пространства.

Аудит:

  • Создана выгрузка событий аудита.

  • Удален файл из события аудита.

Команды:

  • Создана команда.

  • Удалена команда.

  • Обновлена команда.

  • Добавлена команда рабочего пространства.

  • Удалена команда рабочего пространства.

  • Обновлена команда рабочего пространства.

Коннекторы:

  • Синхронизирован каталог коннекторов — техническое событие.

  • Подключен коннектор — пользователь авторизовался в коннекторе.

  • Отключен коннектор — пользователь вышел из аккаунта в коннекторе.

  • Изменено состояние коннектора — включение и выключение коннектора для пользователей, а также изменение в его инструментах.

Файлы:

  • Удален файл — из пространства.

  • Переименован файл — в пространстве.

  • Загружен файл — в пространство.

  • Загружена группа файлов сессии — пользователь загрузил файлы в задачу.

  • Недавний файл скопирован в сессию.???

  • Удален файл из сессии — пользователь удалил файл из задачи.

  • Загружен файл сессии — пользователь загрузил один файл в задачу.

Онбординг:

  • Обновлено состояние онбординга.

Сессии:

  • Отправлено сообщение.

  • Запрошена отмена запуска.

  • Обновлена конфигурация агента сессии.

  • Обновлен канвас сессии.

  • Создана сессия.

  • Удалена сессия.

  • Сессия добавлена в избранное.

  • Переименована сессия.

  • Сессия удалена из избранного.

Навыки:

  • Создан навык.

  • Удален навык.

  • Обновлен навык.

  • Добавлен навык рабочего пространства.

  • Удален навык рабочего пространства.

  • Обновлен навык рабочего пространства.

Рабочее пространство:

  • Рабочее пространство восстановлено из архива.

  • Архивировано рабочее пространство.

  • Создано рабочее пространство.

  • Удалено рабочее пространство.

  • Рабочее пространство добавлено в избранное.

  • Добавлен участник рабочего пространства.

  • Удален участник рабочего пространства.

  • Изменена роль участника рабочего пространства.

  • Рабочее пространство восстановлено из корзины.

  • Изменено состояние корзины рабочего пространства.

  • Рабочее пространство удалено из избранного.

  • Обновлено рабочее пространство.

Просмотр текста сообщения

У некоторых событий есть текст сообщения с деталями события. Для его просмотра, в разделе Администрирование → Аудит событий нажмите на событие в таблице или выберите в строке → Подробнее — откроется окно события, где будет поле Текст сообщения.

Удаление файла события

Вы можете удалить файл, связанный с событием.

Файл удалится из всех мест системы, куда был добавлен.

Для удаления файла события, в разделе Администрирование → Аудит событий, в строке с событием выберите → Удалить или в окне события нажмите Удалить рядом с названием файла.

Экспорт событий

События можно экспортировать. Для экспорта событий, в разделе Администрирование → Аудит событий нажмите Экспортировать журнал и выберите необходимый формат.

Форматы экспорта событий:

  • CSV.

  • NDJSON.

  • Syslog (RFC5424).
