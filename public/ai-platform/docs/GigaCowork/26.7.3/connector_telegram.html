Telegram

Доступные операции

Нажмите, чтобы раскрыть

  • Отправить сообщение — Текстовое сообщение в чат/группу/канал.

  • Ответить на сообщение — Reply на конкретное сообщение.

  • Закрепить сообщение — Закрепить сообщение в чате.

  • Удалить сообщение — Удалить сообщение из чата.

  • Создать опрос — Голосование с вариантами ответов.

  • Получить участника чата — Информация об участнике.

  • Дать права администратора — Назначить админа в чате.

  • Заблокировать участника — Забанить пользователя.

  • Разблокировать участника — Разбанить пользователя.

Особенности подключения

Обмен сообщений GigaCowork с Telegram осуществляется через специального бота. Для авторизации потребуется API-ключ существующего или нового бота.

Создание бота

Чтобы создать бота:

  1. Отправьте боту @BotFather команду /start.

  2. Для создания нового бота отправьте команду /newbot.

  3. Укажите имя бота — оно будет отображаться для всех пользователей.

  4. Укажите имя пользователя (username). Оно должно:

    • Начинаться с символа @.

    • Обязательно заканчиваться на bot. Пример: youNamebot или youName_bot.

  5. После создания бот предоставит API-ключ — скопируйте его.

Выбор существующего бота

  1. Отправьте боту @BotFather команду /mybots.

  2. Выберите нужного бота из списка.

  3. Запросите API-ключ для подключения.

Важные ограничения

Ограничения
Ограничение Описание

Бот должен быть в чате

Чтобы отправить сообщение в группу/канал, бот должен быть добавлен в этот чат как участник

Только цифровой ID

Все отправки работают только по цифровому ID чата/пользователя. Username (@name) не поддерживается

Права бота

В группах боту нужны права на отправку сообщений (проверьте настройки группы)

Пользователи пишут боту первыми

Бот не может написать пользователю первым — пользователь должен сначала запустить бота (/start)

Тип Формат ID Пример

Личный чат

Положительное число

123456789

Группа

Отрицательное число

-1001234567890

Супергруппа

Как получить ID чата/группы/пользователя

Способ 1: Через бота @userinfobot (для личных ID)

  1. Откройте @userinfobot в Telegram

  2. Нажмите /start

  3. Бот вернёт ваш цифровой ID

Способ 2: Через бота @getmyid_bot (для групп и каналов)

  1. Добавьте @getmyid_bot в нужную группу/канал

  2. Бот автоматически отправит сообщение с ID чата

  3. Скопируйте ID из сообщения (будет в формате -1001234567890)

  4. Удалите бота из чата после получения ID (опционально)

Способ 3: Через веб-версию Telegram

  1. Откройте https://web.telegram.org

  2. Перейдите в нужный чат/группу/канал

  3. Посмотрите на URL в адресной строке:

    1. Для личных чатов: …​/c/123456789/…​ → ID = 123456789

    2. Для групп/каналов: …​/c/-1001234567890/…​ → ID = -1001234567890

Способ 4: Через API (для разработчиков)
Метод: getUpdates
URL: https://api.telegram.org/bot<TOKEN>/getUpdates

Отправьте сообщение в чат с ботом, затем вызовите метод — в ответе будет chat.id

Способ 5: Добавить своего бота в группу

  1. Добавьте вашего бота в целевую группу/канал

  2. Отправьте любое сообщение в группу (упомяните бота или нет)

  3. Используйте метод getUpdates или посмотрите логи бота — там будет ID чата

  4. Важно: бот должен оставаться в группе для отправки сообщений

Примеры использования

Отправить сообщение в группу:
Требуемые данные:
- chat_id: -1001234567890 (цифровой ID группы)
- text: "Коллеги, напоминание о совещании в 15:00"

Важно:
- Бот должен быть добавлен в эту группу
- ID должен быть в формате с минусом для групп
Отправить сообщение пользователю:
Требуемые данные:
- chat_id: 123456789 (цифровой ID пользователя)
- text: "Здравствуйте! Ваша заявка обработана"

Важно:
- Пользователь должен сначала запустить бота (/start)
- Бот не может написать первым неизвестному пользователю
Создать опрос:
Требуемые данные:
- chat_id: -1001234567890
- question: "Выберите дату встречи"
- options: ["Понедельник", "Среда", "Пятница"]
- is_anonymous: false (опционально)

Частые ошибки

Ошибка Причина Решение

Chat not found

Неверный ID чата

Проверьте формат ID (с минусом для групп)

Bot is not a member

Бот не в чате

Добавьте бот в группу/канал

Bot can’t send messages

Нет прав у бота

Проверьте права бота в настройках группы

Blocked by user

Пользователь заблокировал бота

Свяжитесь другим способом

Bot was kicked

Бот удалён из чата

Добавьте бота повторно

Message not modified

Текст не изменился

Измените содержимое сообщения

Bad Request: chat_id is empty

Не указан ID

Передайте цифровой ID в параметрах
