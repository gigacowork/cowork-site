Яндекс Почта

Доступные операции

Нажмите, чтобы раскрыть

  • Отправка письма по SMTP.

  • Проверка только по одному входящему письму из почты.

Особенности подключения

Пример авторизации:
https://files.sberdisk.ru/s/eiIAJUvHaQXxH2B

Для подключения Яндекс Почты необходимо настроить доступ по протоколу SMTP и создать пароль приложения в аккаунте Яндекс ID.

Настройка SMTP
Для настройки отправки по протоколу SMTP:

  1. Войдите в свой аккаунт Яндекс почты.

  2. Откройте Настройки → Почтовые программы.

  3. Разрешите доступ к почтовому ящику:

    • с сервера imap.yandex.ru по протоколу IMAP;

    • с сервера pop.yandex.ru по протоколу POP3.

  4. Сохраните изменения.

Создание пароля приложения

Если в способе авторизации по IMAP выбрано Пароли приложений и OAuth-токены, необходимо создать пароль приложения.

Для создания пароля приложения:

  1. Перейдите во вкладку Пароли приложений,откроется страница с информацией о паролях приложений, откуда необходимо перейти во вкладку Безопасность.

  2. Прокрутите страницу вниз и перейдите во вкладку Пароли приложений.

  3. Выберите тип приложения Почта.

  4. Придумайте название пароля — например, укажите название приложения, для которого создаётся пароль. С этим названием пароль будет отображаться в списке.

  5. Нажмите кнопку Далее — пароль приложения отобразится во всплывающем окне.

  6. Скопируйте и сохраните пароль.

    Пароль показывается только один раз.

  7. Дождитесь активации пароля.

    Пароль для приложений начинает действовать спустя 2–3 часа после создания.
