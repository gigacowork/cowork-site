# БИЗНЕС-КОНТЕКСТ

Мы продаем платформу GigaCowork / GigaChat Business — платформу для создания и управления корпоративными ИИ-агентами.

Цель встречи с клиентом — показать не абстрактный ИИ, а конкретные сценарии агентов, которые могут:

- искать знания в корпоративных документах;
- обслуживать типовые запросы сотрудников или клиентов;
- проводить исследования;
- извлекать и структурировать данные из документов;
- выполнять действия в корпоративных системах через коннекторы;
- готовить документы, таблицы, справки, заявки и отчеты;
- снижать ручную текстовую, бюрократическую и коммуникационную рутину.

Фокус только на Text-Heavy / Knowledge-Heavy / Process-Heavy задачах.

ИГНОРИРУЙ сценарии, где основной эффект связан с:

- Computer Vision;
- IoT;

- промышленным железом;
- физическими датчиками;
- видеоаналитикой;
- предиктивным обслуживанием оборудования на телеметрии, если там нет сильного текстового слоя.

Разрешены только те производственные сценарии, где есть текстовые документы, регламенты, сменные отчеты, заявки, инструкции, протоколы, дефектовки, переписка, ERP/1С/Excel/документооборот.

# КЛАССИФИКАЦИЯ АГЕНТОВ

Все найденные сценарии классифицируй по одному или нескольким типам:

## 1. Агент знаний и навигации
Ищет ответы в документах, регламентах, инструкциях, базе знаний. Дает ответ с источником.

Примеры:
- поиск по регламентам;
- ответы на вопросы сотрудников;
- навигация по инструкциям;
- юридический или закупочный помощник по базе документов.

## 2. Агент самообслуживания / Service Desk
Принимает запрос, уточняет данные, отвечает на типовые вопросы, создает обращение или эскалирует человеку.

Примеры:
- HR FAQ;
- IT Service Desk;
- поддержка внутренних пользователей;
- обработка заявок сотрудников;
- ответы поставщикам или клиентам по типовым вопросам.

## 3. Агент исследований и анализа
Собирает данные из разных источников, сравнивает, готовит аналитическую справку.

Примеры:
- подготовка к встрече с клиентом;
- поиск поставщиков;
- анализ конкурентов;
- анализ отраслевых кейсов;
- исследование рынка;
- account research.

## 4. Агент извлечения и структурирования
Извлекает данные из документов, писем, PDF, Excel, Word, форм и приводит их к структуре.

Примеры:
- сравнение коммерческих предложений;
- анализ резюме;
- извлечение условий договора;
- обработка счетов, актов, заявок;
- нормализация данных для Excel/ERP/CRM.

## 5. Агент действий и автоматизации
Выполняет действие в системе после проверки человеком или по правилам.

Примеры:
- создание заявки;
- заполнение карточки в CRM/ERP;
- обновление статуса;
- формирование документа;
- запуск согласования;
- отправка follow-up.
