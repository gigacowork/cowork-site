# Анализ эффективности каналов

**Степень свободы:** низкая в атрибуции и KPI; средняя в выводах о перераспределении.

## Предусловия

Нужны нормализованные `Sources`, `Touchpoints`, лиды/сделки и, для стоимости,
`Marketing_Performance`.

## Не использовать

- stage conversion как «мультиканальную атрибуцию»;
- attribution policy, которую не утвердил клиент;
- ROAS/CAC без расходов и корректного связывания продаж;
- причинную формулировку на основании одной наблюдаемой корреляции.

## Рабочий процесс

- [ ] Проверить уникальность source/campaign ids и покрытие touchpoints.
- [ ] Построить канал → лид → сделка без смешения периодов.
- [ ] Применить одну явно указанную модель атрибуции.
- [ ] Проверить сумму attribution weights по контакту/сделке = 1.
- [ ] Рассчитать CPL/CAC/конверсии только при наличии знаменателей.
- [ ] Выделить drop-off и каналы-кандидаты для теста/перераспределения.

## Выход

`channel_funnel`, `attribution`, `unit_economics`, `drop_off`,
`recommendations`, `evidence`, `limitations`.

## Исполнение расчёта

Если расчёт требует Python, прочитай код из `Референсы/calculate.py` и передай его в `python_run`.

## Ресурсы навыка

Дополнительные материалы вынесены в подпапку `Референсы/`:
- `Референсы/calculate.py` — расчёт атрибуции каналов;
- `Референсы/МЕТОДИКА.md` — методика анализа каналов;
- `Референсы/СХЕМА_РЕЗУЛЬТАТА.json` — JSON Schema результата.

Подгружай файл из `Референсы/` только когда он нужен для текущего шага.
