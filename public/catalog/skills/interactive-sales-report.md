# Формирование интерактивного отчёта

**Степень свободы:** средняя в компоновке; нулевая в пересчёте бизнес-метрик.

## Главный принцип

Этот навык **только представляет** проверенные результаты. Он не пересчитывает
воронку, прогноз, SLA, атрибуцию, scoring, plan-fact и рекомендации.

## Режим по умолчанию

1. Активируй `sys-infographics` и построй интерактивную визуализацию только по
   фактически доступным секциям.
2. Сохрани связь каждого KPI с периодом/as-of и evidence.
3. Если данных для блока нет — убери блок или явно покажи `недоступно`.

## HTML по явному запросу

Если пользователь прямо просит `.html`:

- используй встроенный `files` и создай один UTF-8 файл в `/session`;
- встрои CSS/JS/данные внутрь файла, без CDN, внешних библиотек и web fonts;
- не выполняй сетевые запросы из HTML;
- фильтры могут сортировать/скрывать уже рассчитанные строки, но не менять
  формулу KPI;
- проверь файл по `Референсы/HTML_ЧЕКЛИСТ.md` перед выдачей.

## Не использовать

- на сырых CRM-данных вместо аналитического навыка;
- для «красивого» заполнения отсутствующих показателей;
- для скрытого пересчёта исходных цифр JavaScript-кодом.

## Рабочий процесс

- [ ] Определить verified источники результата.
- [ ] Выбрать только доступные управленческие представления.
- [ ] Сформировать визуализацию/HTML без изменения чисел.
- [ ] Добавить data gaps, source conflicts и ограничения.
- [ ] Проверить читаемость и соответствие исходным значениям.

## Ресурсы навыка

Дополнительные материалы вынесены в подпапку `Референсы/`:
- `Референсы/HTML_ЧЕКЛИСТ.md` — чек-лист самодостаточного HTML;
- `Референсы/СТРУКТУРА_ОТЧЁТА.md` — структура интерактивного управленческого отчёта;
- `Референсы/СХЕМА_РЕЗУЛЬТАТА.json` — JSON Schema результата.

Подгружай файл из `Референсы/` только когда он нужен для текущего шага.
