# Распределение лидов

**Степень свободы:** низкая в ranking; средняя в объяснении рекомендации.

## Предусловия

Нужны `Lead_Segments`, `Manager_Segment_Performance`, нагрузка/capacity и
утверждённые веса. Чувствительные признаки запрещены.

## Не использовать

- protected/sensitive attributes;
- сырую конверсию без smoothing на малой выборке;
- recommendation при `processed < minimum_segment_sample` для всех кандидатов;
- score как «вероятность продажи».

## Рабочий процесс

- [ ] Определить сегмент лида и его версию.
- [ ] Отфильтровать недопустимых/недоступных менеджеров.
- [ ] Рассчитать smoothed conversion, normalized avg check и capacity score.
- [ ] Проверить minimum sample gate.
- [ ] Построить ranking и confidence.
- [ ] Запись владельца выполнять только по отдельному подтверждённому протоколу.

## Базовая формула

`0.50 × conversion_smoothed + 0.30 × avg_check_norm + 0.20 × capacity_score`.
Веса — конфигурируемые; если клиент их меняет, зафиксируй новую версию.

## Выход

`lead_segment`, `eligible_managers`, `ranking`, `recommended_manager`,
`confidence`, `rationale_evidence`, `limitations`.

## Исполнение расчёта

Если расчёт требует Python, прочитай код из `Референсы/calculate.py` и передай его в `python_run`.
