# Оценка качества менеджеров

**Степень свободы:** средняя при извлечении evidence из текста; низкая при scoring.

## Предусловия

Нужны транскрипт/диаризация и утверждённая рубрика. Для оценки темпа, пауз и
просодики нужны отдельные аудиопризнаки; текста недостаточно.

## Не использовать

- для вывода об эмоциях/уверенности только по транскрипту;
- для придумывания реплик, которых нет в записи;
- для изменения весов рубрики «по ощущению»;
- для дисциплинарного решения без human review.

## Рабочий процесс

- [ ] Прочитать рубрику и веса блоков.
- [ ] Если `detected_blocks` отсутствует, сначала извлечь evidence из **сырого транскрипта**:
  каждый отмеченный блок должен иметь точную опору в тексте; затем передать только labels
  в детерминированный scoring.
- [ ] Для каждого критерия найти цитируемое evidence или отметить отсутствие.
- [ ] Отделить transcript evidence от acoustic features.
- [ ] Рассчитать score по утверждённой рубрике.
- [ ] Сформировать coaching card: сильные стороны, пробелы, следующий навык.
- [ ] На уровне команды агрегировать только повторяющиеся паттерны.

## Выход

`call_scorecards`, `manager_coaching_cards`, `team_patterns`, `evidence`,
`audio_available`, `limitations`.

## Проверка LLM-шага

В демо обязательно отдельно прогони `Демо_Call_Transcript_Raw.csv` без `detected_blocks`
и сравни поддержку блоков с `ОЖИДАЕМЫЙ_LLM_EVIDENCE.json`. Этот сценарий не входит в
числовую регрессию: он проверяет evidence extraction и запрет выдуманных блоков.

## Исполнение расчёта

Если расчёт требует Python, прочитай код из `Референсы/calculate.py` и передай его в `python_run`.
