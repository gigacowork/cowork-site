# Анализ отклонений от плана

**Степень свободы:** низкая в расчёте; средняя в управленческой формулировке.

## Предусловия

Нужны утверждённая версия `Plans`, факт на дату среза и/или verified forecast.
Для факторной декомпозиции нужны `Plan_Drivers` либо другой утверждённый baseline.

## Не использовать

- усреднение нескольких активных версий плана;
- выдуманные причины отклонения при отсутствии driver data;
- Shapley decomposition без сопоставимой плановой и фактической модели.

## Рабочий процесс

- [ ] Выбрать единственную активную версию плана и зафиксировать её.
- [ ] Рассчитать факт и отклонение к дате среза.
- [ ] Добавить forecast variance, если есть валидированный прогноз.
- [ ] При наличии drivers выполнить декомпозицию и проверить reconciliation error.
- [ ] Выделить первичный/вторичные факторы и уровень эскалации.

## Выход

`plan_performance`, `actual_variance`, `forecast_variance`, `variance_drivers`,
`primary_driver`, `secondary_drivers`, `management_escalation`, `evidence`,
`limitations`.

## Исполнение расчёта

Если расчёт требует Python, прочитай код из `Референсы/calculate.py` и передай его в `python_run`.

## Ресурсы навыка

Дополнительные материалы вынесены в подпапку `Референсы/`:
- `Референсы/calculate.py` — as-of реконструкция состояния, план-факт и Shapley-декомпозиция;
- `Референсы/МЕТОДИКА.md` — методика план-факт и декомпозиции;
- `Референсы/СХЕМА_РЕЗУЛЬТАТА.json` — JSON Schema результата.

Подгружай файл из `Референсы/` только когда он нужен для текущего шага.
