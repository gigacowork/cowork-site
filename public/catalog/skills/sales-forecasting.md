# Прогнозирование продаж

**Степень свободы:** низкая в моделях/интервалах; средняя в объяснении факторов.

## Предусловия

Нужны подготовленные `Sales_History_Monthly`, актуальный pipeline и правила
признания продажи. Текущий период и будущий полный период обрабатываются разными
политиками.

## Не использовать

- годовую сезонность при истории <24 месяцев;
- ensemble ETS+pipeline без backtest-калиброванных весов;
- `confidence grade` вместо числовых 80/95 интервалов;
- калибровку интервала на in-sample residuals или чужом `model_signature`.

## Рабочий процесс

- [ ] Проверить длину истории и качество временного ряда.
- [ ] Построить ETS/Holt baseline по допустимому режиму.
- [ ] Построить pipeline forecast на as-of без будущих событий.
- [ ] Выполнить expanding-window backtest и сравнить с naive baseline.
- [ ] Оценить 80/95 интервалы и статус их калибровки.
- [ ] Выбрать operational forecast по политике текущего/будущего периода.
- [ ] Объяснить факторы и ограничения, не меняя числовой результат.

## Политика истории

- `<6` месяцев: ETS недоступен; только допустимый fallback/pipeline.
- `6–23` месяца: Holt/ETS без годовой сезонности.
- `>=24` месяцев: допускается additive Holt-Winters `m=12`.

## Выход

`ets_baseline`, `pipeline_forecast` (включая `expected_revenue` и `expected_units`), `operational_forecast`, `interval_80`,
`interval_95`, `backtest_quality`, `interval_calibration`, `assumptions`,
`evidence`, `limitations`.

## Исполнение расчёта

Если расчёт требует Python, прочитай код из `Референсы/calculate.py` и передай его в `python_run`.

## Ресурсы навыка

Дополнительные материалы вынесены в подпапку `Референсы/`:
- `Референсы/calculate.py` — ETS/Holt baseline, pipeline forecast, калибровка интервалов и backtest;
- `Референсы/МЕТОДИКА.md` — протокол валидации прогноза и интервалов;
- `Референсы/СХЕМА_РЕЗУЛЬТАТА.json` — JSON Schema результата.

Подгружай файл из `Референсы/` только когда он нужен для текущего шага.
