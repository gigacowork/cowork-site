Роли

В разделе Администрирование → Роли можно управлять ролями: создавать, назначать пользователям и отзывать.

Просмотр ролей

Роли в разделе Администрирование → Роли можно фильтровать по типам, по признаку Роль по умолчанию и искать по названию.

Для просмотра деталей роли, нажмите на нее в таблице, откроется окно роли со вкладками: Разрешения — с разрешениями роли, Назначения — со списком пользователей, кому назначена роль.

Типы ролей

Тип роли виден в таблице ролей, в столбце Тип роли, а так же в окне роли.

В системе есть два типа ролей:

  • Системная — предустановленная роль, которую нельзя редактировать и удалять.

  • Пользовательская — роль, созданная администраторами. Такую роль можно редактировать и удалять.

Роль по умолчанию

Роль по умолчанию — это роль, которая назначается пользователю автоматически, если при отправке приглашения не была указана конкретная роль.

Если ролей по умолчанию несколько, они все будут назначены пользователю.

Признак роли по умолчанию виден в таблице ролей, в столбце Роль по умолчанию.

Чтобы поставить или снять признак роли по умолчанию, в окне роли, выберите или уберите чекбокс Установить как роль по умолчанию.

Создание роли

Для создания роли:

  1. В разделе Администрирование → Роли нажмите Создать роль.

  2. Укажите:

    • Название роли.

    • Описание — видно в таблице ролей и в окне роли.

    • Установить как роль по умолчанию — выберите, если создаете роль по умолчанию. Подробнее.

    • Разрешения — выберите разрешения для роли. Подробнее.

Разрешения ролей

Разрешения ролей — это список возможностей, которые может делать пользователь, которому назначена роль.

Разрешения видны при создании или просмотре роли в блоке Разрешения.

Разрешения ролей:

  • Управление коннекторами — видит раздел Администрирование → Коннекторы и может совершать в нем любые действия.

  • Управление ролями — видит раздел Администрирование → Роли и может совершать в нем любые действия.

  • Управление пользователями — видит раздел Администрирование → Пользователи и может совершать в нем любые действия.

  • Управление рабочими пространствами — видит раздел Администрирование → Удаленные объекты и может совершать в нем любые действия.

Назначение и снятие роли

Роли можно назначать как по одной так и по несколько сразу. Снимать роли можно только по одной.

Для назначения одной конкретной роли, в разделе Администрирование → Роли, в строке нужной роли выберите → Назначить или в окне роли нажмите Назначить. Затем в открывшемся окне укажите одного или нескольких пользователей.

Для назначения нескольких ролей сразу, в разделе Администрирование → Роли нажмите Назначить роли и выберите роли и пользователей, которым они будут назначены.

Для снятия роли с пользователя, в разделе Администрирование → Роли откройте роль и в окне роли перейдите на вкладку Назначения. Затем нажмите Отзыв роли рядом с пользователем — изменения вступают в силу сразу.

Редактирование роли

Для редактирования роли, в разделе Администрирование → Роли, в таблице или в окне роли выберите → Редактировать и внесите правки — изменения вступают в силу сразу.

Системные роли недоступны для редактирования.

Удаление роли

Для редактирования роли, в разделе Администрирование → Роли, в таблице или в окне роли выберите → Редактировать и внесите правки — изменения вступают в силу сразу.

Системные роли недоступны для удаления.
