# Очередь голосов через Apps Script

Техническое описание всей системы и порядок установки на сайт: [`VOTING_BACKEND_HANDOFF.md`](../../VOTING_BACKEND_HANDOFF.md).

Участник открывает страницу вопроса без запроса к Google. После выбора ответа сайт сразу показывает «Спасибо, ваш голос учтён» и отправляет один POST с `keepalive`. Ответ фиксируется в `localStorage` этого браузера. На стороне Google `doPost` быстро кладёт голос в Script Properties. Фоновая функция `flushVotingQueue` раз в минуту записывает до 500 ожидающих голосов одной пачкой в лист «Голоса».

Экран результатов считает и записанные, и ожидающие голоса. После переноса пачки один и тот же голос не удваивается: пятый столбец листа хранит уникальный ключ записи.

## Подключение

1. Замените содержимое `Code.gs` в существующем проекте Apps Script кодом из этого каталога и сохраните.
2. Выберите функцию `setupVotingSheet` и запустите её. Она добавит пятый столбец и создаст один минутный триггер. Подтвердите новые разрешения Google.
3. В «Управление развертываниями» обновите **существующее** веб-приложение новой версией. Ссылка `/exec` останется той же.
4. Только после развертывания включите `NEXT_PUBLIC_VOTING_QUEUE_MODE=true` при сборке сайта. На текущем локальном стенде и в шаге `next build` файла `.github/workflows/deploy.yml` значение уже задано. При установке на `cowork.ru` через другой CI задайте его там.
5. Сделайте пробное голосование. Сразу после POST итоговый экран должен увеличить счётчик, а через минуту в листе должна появиться строка с ключом в пятом столбце. Затем повторите нагрузочный тест.

Пока переменная из шага 4 не включена, сайт использует прежний режим с POST и проверкой записи. Это позволяет обновить Apps Script раньше сайта.

## Сброс голосования

Остановите публикацию QR-кодов, запустите в Apps Script `clearVotingQueue`, удалите строки с голосами из листа «Голоса», сохранив заголовок, и поменяйте `VOTING_ROUND_ID` в `src/lib/voting.ts` перед новым развертыванием сайта. Иначе браузеры, уже голосовавшие в этом раунде, продолжат показывать сообщение об успехе.

## Ограничения

- Сообщение участнику появляется до подтверждения записи. Если запрос не дошёл до Apps Script, сайт не узнает об этом. `keepalive` помогает при закрытии вкладки, но не обеспечивает гарантированную доставку.
- Очередь общая для всех браузеров, запросы которых Apps Script успел принять. Google может отклонить вызов ещё до `doPost`; очередь не спасёт такой голос. После смены развертывания или заметного изменения нагрузки повторите нагрузочный тест.
- Script Properties ограничены 500 КБ на проект; голос хранится только до записи пачки в таблицу. При накоплении большой очереди сверх этого лимита новые голоса не будут приняты.
- Минутный триггер может сработать с задержкой, поэтому строки в таблице появятся позже, чем результат на сценическом экране.
